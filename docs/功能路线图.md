# 功能路线图（对标脑图 triage）

> 依据 2026-11-14 的「Work Ai Bot AI应用生成SaaS系统」脑图做的功能对照与取舍记录。

## ✅ V3.1 新增（本次交付）

1. **F 型后台结构**：左侧深色侧边栏（分组导航）+ 顶栏 + 内容区；工作台 / 员工中心同套外壳。
2. **数据概览仪表盘**：六张统计卡 + 最近动态。
3. **知识库 MVP**：见上表；检索为关键词级（中文 bigram + IDF），语义向量检索留待后续。
4. **多模型兼容**：OpenAI 兼容接口风格。
5. **系统信息页**：版本 / 运行环境 / 数据规模只读展示。

## ⏭ 暂不实施（「UMI 企业智脑」脑图补充，与「Work Ai Bot」脑图合并记录）

| 脑图分支 | 原因 / 备注 |
| --- | --- |
| 多语言（10 语种） | 内部工具用户单一；i18n 框架化改造工作量大，待有真实需求再做 |
| 邮箱 / Google / GitHub OAuth 登录 | 内部账号体系已闭环；OAuth 需要外网回调与第三方应用注册，私有化部署场景收益低 |
| 知识库 · QA 拆分 / 精准数据导入 / 向量检索 | MVP 先行；Embedding 向量检索与 QA 生成模型需嵌入 API 依赖（参考站的 Embedding Model / 问答生成模型），违背零依赖约定，需专项评估 |
| 工作流 · 判断器 / 问题分类 / HTTP 模块 / 应用调用 | 画布工作流 MVP 已含主链 DAG（entry / ai / kb / reply）；分支判断与外部调用节点待后续版本 |
| 「我的应用」应用体系（应用网格 + 每应用独立配置/日志/权限） | 与现有「智能体 + API 配置 + 运行日志」体系重叠，重构成本高，待评估合并方案 |
| 桌面插件 / 对外分享 QPM | 需独立桌面端开发 / 分享限流组件，待有需求立项 |
| 高级编排 / 模块（判断器 / HTTP 模块 / 问题分类等） | 属于独立的应用编排产品形态，与对话工作台定位不同 |
| 支付（微信 / PayPal）· 充值 · 财务 · 套餐计划 | 内部工具无商业化场景；如转 SaaS 需整体立项 |
| 通知中心 | 可用现有审计 + 日志替代；有需求时可加站内信 |
| 训练模型 / 训练数据（UMI 脑图） | 需要训练基础设施与 GPU 资源，超出工作台形态 |
| 数据仓库（OA / ERP / CRM / MES / HRMS / SCM 对接） | 需逐系统定制集成，属独立实施项目 |
| 智能营销（企业营销信息库 / IP 打造 / 付费投流 / 舆情监控） | 需外部数据源与营销平台 API，非内部工具范畴 |
| AIGC 音频 / 视频 / 3D 生成 / 音乐 | 需专用多模态生成 API（当前仅对接文本对话与文生图） |
| 桌面插件 | 需独立桌面端开发（Electron 等），待有需求立项 |
| 计费管理 / 风控管理 / 字典管理 / 协议 | 面向 SaaS 运营的能力，内部工具无对应场景；风控已由审计日志 + 登录限流覆盖 |
