
## 移动端工作台布局修复（用户截图反馈三个问题）

- **问题 1 输入框看不到**：根因是旧浏览器（无 dvh 支持的 WebView/微信 X5）里 `100vh` 把页面撑到浏览器工具栏后面；且基础规则 `body { min-height: 100vh }` 会覆盖 height。修复：index.html `<head>` 内联脚本用 `window.innerHeight` 实时同步 CSS 变量 `--app-h`（resize/orientationchange/visualViewport 键盘场景），`body.wb-page` 高度链改为 `100vh → 100dvh → var(--app-h, 100dvh)` 并加 `min-height: 0`。
- **问题 2 顶栏按钮排版**：登录后 6 个按钮换行成凌乱两行（实测顶栏 90px）。修复：≤720px 顶栏改单行 52px（品牌在左），动作区收进「⋯ 更多」下拉面板；新增共享脚本 `public/assets/topbar-more.js`，三个页面（index/admin/me）body 加 `has-more` 类启用，桌面端不受影响。
- **问题 3 抽屉不能完全展开**：`max-height: 36vh` 从 ≤900px 媒体查询泄漏到 ≤720px 的 `.sidebar`（实测抽屉只有 307px/852px 视口）。修复：`body.wb-page .sidebar { max-height: none }` + 清掉泄漏的 border-bottom，恢复整屏高度、内部滚动。
- 验证方式：playwright-cli 移动端视口（393×852 / 360×640）+ 模拟登录态 + `--app-h` 调小模拟旧浏览器可见区，全部通过；桌面端与 13 项单测回归通过。
