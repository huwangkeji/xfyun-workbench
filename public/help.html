同聪星火使用指南

团队大模型对话工作台 · 私有化部署 · 数据在自己手里

🚀 快速上手

  1. 管理员在 后台管理 → 模型配置 添加模型配置（API 地址 / Key / 模型名），第一个配置自动设为默认。
  2. 进入 工作台，左侧选择 模型配置，点击「＋ 新增对话」。
  3. 输入问题，Enter 发送，Shift+Enter 换行。
  4. Ctrl+V 直接粘贴图片，或拖拽 / 点击 📎 上传（单张 ≤8MB，最多 9 张）。

🤖 智能助手与知识库

  • 智能助手：侧栏「智能助手」下拉选择角色（售前顾问、周报生成、会议纪要等），角色设定自动注入对话；可在「📝 系统提示」中微调。
  • 深度思考：开启后模型推理更充分，耗时更长；强度 high 均衡 / max 最强。
  • 联网搜索：按次开关，获取实时信息。
  • 知识库：开启并选择库后，每次提问自动检索最相关的分段注入上下文（需管理员在后台「知识库」导入资料；仅登录员工可用）。
  • 以上设置都会记住选择，下次进入无需重设。

🔗 分享与协作

  • 对话头部「🔗 分享对话」生成只读链接（快照内容，继续对话不影响已发出的链接），可选 7 / 30 / 90 天或永久，可随时撤销。
  • 发现链接泄露：分享弹窗中「撤销」即刻失效。
  • 成员管理（后台）：创建 / 停用员工账号，四级角色权限（owner / admin / member / viewer），数据按人隔离。

❓ 常见问题

  • 提示「扣费失败 / 上游限流」？ 多配置自动调度会在故障时切换备用配置；确认 API Key 有效与余额。
  • 想换对话模型？ 侧栏「选中的模型配置」切换；不同配置可绑定不同模型与参数。
  • 忘记员工密码？ 联系管理员在后台「成员管理 → 重置密码」，或双击 启动.bat 选 [4] 自助重置 owner 密码。
  • 历史会话在哪？ 工作台侧栏「会话」列表；管理员可在后台「记忆管理」检索全部会话。
  • 数据存在哪？ 本地 data/db.json（原子写），API Key 可选加密存储；无第三方上报。
