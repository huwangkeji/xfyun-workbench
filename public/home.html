多模型对话

多配置自动调度

多个 API 配置按优先级自动切换，失败自动冷却重试；Key 用量与延迟一目了然。

图片理解

请求量、成功率、token 消耗、平均耗时、活跃成员，管理员一屏掌握团队使用情况。

记忆与导出

安全管控

为团队数据画的每一条红线

操作留痕

登录成败、账号变更、配置变更、数据删除全部记录，最近 2000 条随时可查。

数据隔离

会话与日志按归属人隔离：成员只看自己的，管理员看全部，访客只见访客桶。

密钥安全

API Key 仅从环境变量或后台读取，可选 AES-256-GCM 加密落库，源码零硬编码。

稳定写入

数据文件原子写入，进程中断不损坏；单文件备份，迁移就是拷一个文件。

使用你的员工账号登录，或联系管理员开通账号。忘记密码可让管理员重置。

员工登录 注册账号 进入工作台
没有账号怎么办？

账号由管理员在后台「成员管理」创建；若站点开放了自助注册，登录页会出现注册入口。

忘记密码怎么办？

联系管理员在「成员管理」中重置密码，会生成临时密码，下次登录需改密。

数据存放在哪里？

全部数据保存在服务器本地单文件中，私有部署，备份即拷贝该文件。
