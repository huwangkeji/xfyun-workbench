工作台访问控制（访客密码）
开启前需先设置访客密码；关闭后工作台恢复开放。后台登录态默认放行工作台（Owner 无需重复输入）。密码 scrypt 哈希存储；同 IP 连续 5 次密码错误锁定 60 秒；会话有效期 12 小时。
界面显示设置
关闭后前端面板只显示配置名称（如「星火」），不再展示模型 ID（如 spark-x2.6）；对话气泡下方的响应明细仍会显示实际模型。默认开启。
多 API 调度策略
调度顺序：默认配置（标记为「默认」的）优先 → 其次按「调度优先级」从小到大 → 最后按创建时间。故障配置会进入冷却期，冷却结束后自动恢复参与调度。每个 API 配置可在下方「参与自动调度」「调度优先级」中设置。
