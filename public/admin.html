智能体 = 预设角色（名称 / 头像 / 角色设定 systemPrompt）的对话助手。工作台侧栏选择后，角色设定随对话注入模型。内置「数字员工」（售前 / 售后 / 人事 / 财务等）与「提效工具」（周报 / 纪要 / 宣传文案）模板可一键导入。
MCP（Model Context Protocol）服务：配置外部 MCP Server（stdio 启动命令），连接成功后自动发现其暴露的工具，供智能体在对话中调用。支持环境变量、参数，可测试连接。
